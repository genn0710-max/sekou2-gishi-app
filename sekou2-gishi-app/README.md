# 2級建築施工管理技士 絶対合格プログラム

**第1次検定（四肢択一試験）** から **第2次検定（実地試験・経験記述）** までを完全攻略するための、完全スタンドアローン型学習アプリケーションです。

---

## 🌟 特徴と合格メソッド

1. **第1次検定 攻略（本番模擬試験 ＆ 分野別特訓ドリル）**
   - 建築学（環境・構造・材料）、躯体・仕上施工、施工管理法（工程・品質・安全）、建築法規の最新シラバス・頻出重要問題を網羅。
   - すべての選択肢に「なぜ正しいのか／どこが誤りなのか」の理由付き詳細解説。
   - 制限時間付きタイマー、見直しフラグ（🚩）、一目でわかる問題パレット、合否判定レポート。
   - 間違えた問題だけを復習できる「弱点克服モード」。

2. **第2次検定 攻略【経験記述マスター＆リアルタイムAI自己診断】（最重要！）**
   - 2次試験最大の関門である「経験記述」を、自分の現場に合わせて入力・添削。
   - 「品質管理」「安全管理」「工程管理」の合格模範文例をワンクリック参照＆コピー可能。
   - **リアルタイムAI添削機能**：
     - 絶対避けるべき抽象的NG表現（「注意深く行った」「十分確認した」等）を検知。
     - 具体的な管理数値（寸法・温度・日数・時間・比率等）の有無を分析。
     - 課題 → 検討 → 措置・結果 の3段論法と文字数バランスをスコアリング（100点満点・ランク判定）。

3. **第2次検定 攻略【実地記述・工程表特訓】**
   - 躯体工事・仕上工事の施工留意点記述（暑中コンクリート、かぶり厚さ、シーリング等）。
   - ネットワーク工程表のクリティカルパス日数計算・最早最遅時刻の演習。

4. **超頻出！重要数値・判定基準 暗記カード**
   - スランプ許容差（±2.5cm）、湿潤養生期間（普通ポルトランド5日以上）、ガス圧接（1.4倍・1.2倍）、足場手すり高さ（85cm以上）など、試験に出る重要数値を3D反転カードで高速暗記。

5. **完全スタンドアローン ＆ ゼロ外部依存**
   - Python 3 標準ライブラリのみで動作（`pip install` などのインストール作業は一切不要）。
   - 空きポート自動探索（他のアプリとポートが被っても自動で切り替え）。
   - 自作問題の追加や経験記述の下書きもローカルに自動保存。

## 🚀 起動方法

### 方法1: ワンクリック起動（Mac）
ターミナルで本フォルダに移動し、以下を実行します：
```bash
./run.sh
```
※ 自動的にサーバーが起動し、標準ブラウザでアプリ画面が開きます。

### 方法2: 通常起動
```bash
python3 server.py
```
ターミナルに表示されるURL（例: `http://localhost:8766`）にブラウザでアクセスしてください。

```
└── data/
    ├── categories.json        # 分野体系データ

    ├── questions_2nd.json     # 第2次検定 実地記述・工程表問題

    └── user_state.json        # ユーザー学習履歴・下書き保存ファイル
```
